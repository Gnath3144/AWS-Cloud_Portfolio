# Enterprise PDF Downloads Directory

This directory stores downloadable production PDF assets:
- `gopinath-resume.pdf`: Executive Resume & Technical Dossier
- `databricks-training-brochure.pdf`: Databricks Corporate Masterclass Brochure
- `course-catalog.pdf`: Enterprise Course & Workshop Syllabus Catalog
- `akef-whitepaper.pdf`: Autonomous AI Knowledge Engineering Framework Specification

When deployed on static hosting (GitHub Pages), the client-side document modal (`window.openDocumentModal()`) provides an interactive document preview, print-ready document summaries, and tailored dossier request dispatching.
